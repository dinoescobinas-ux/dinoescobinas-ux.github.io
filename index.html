NTE Sales Mailer

NTE Sales Mailer is a private internal tool. Every morning it sends month-to-date sales reports from the company mailbox nteupdate@gmail.com to the company's own salesmen and sales managers.

It uses the Gmail API only to send those report emails and to read the headers (subject, recipient, date) of mail already sent, so that no report is sent twice on the same day. It does not read the content of any email, and it is not offered to the public.
